help is the index.  There are enough commands now that one list is a
wall rather than an answer, so they are gathered into groups and this
prints the groups: a name, what the group is for, and how many commands
are in it.  Naming one lists its commands with the line that says how
each is typed, and "help all" is every command at once, which is what
help printed before there were groups.

The groups are the questions somebody has -- how do I look at
inventory, how do I talk to somebody, which avatar am I driving -- and
not a map of the source.  Nothing in them follows which file a command
lives in, and several deliberately cut across it.

# A command may be in more than one group

Copying an item is an inventory operation, and it is also how an avatar
that may not rez gets another object, so it is listed under both.
Looking in either place finds it.  A listing that put every command in
exactly one place would be tidier and would answer fewer questions.

# It never describes a single command

That is the command's own business, and there are two ways to ask it:
the command itself says what it takes, and man says what it is for and
where it will surprise you.  So asking help about a command is answered
by pointing at those two rather than by refusing -- that being the
moment somebody wants to know -- and a word that is neither a group nor
a command is an error, since it is a typo.

It also means a name can be both a group and a command without
ambiguity: here it always means the group.

# Examples

	help
	help region
	help all > commands

See also: man, and the command itself, which answers what it takes.
