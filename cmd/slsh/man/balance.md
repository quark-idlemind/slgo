balance asks the grid how many L$ this avatar has, and prints the
answer.

    balance

It asks every time.  Nothing here keeps a balance to answer from,
because it changes whenever anybody pays this avatar or is paid by it,
from this shell or from anywhere else, and a figure remembered from
earlier would be an answer about earlier.

The grid answers in well under a second on a quiet region.  A busy one
can take much longer, so the wait is fifteen seconds before the command
says nothing came.

## Examples

    balance
    L$120

See also: `pay` for paying somebody, which reads the balance before it
pays and says the balance after.
