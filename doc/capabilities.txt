# Every capability a viewer asks the seed capability for, one per line.
#
#   name                          verb  what it is for
#
# A capability is a URL the simulator hands out, and the seed capability
# is the one URL you are given at login.  Post it a list of names and it
# answers with a URL for each one it has.  Asking for a name that does
# not exist is harmless: the reply simply leaves it out, which is also
# how a capability that has been retired disappears.  Nothing here can
# be reached without asking for it first.
#
# The list is the 119 names Firestorm asks for.  116 of them are
# literals in llviewerregion.cpp; the other three are added elsewhere
# through named constants -- InventoryAPIv3 and LibraryAPIv3 from
# llaisapi.cpp, on a differently named list, and VETPBR from a constexpr
# in llviewerregion.cpp.  Grepping for the literals alone finds 116 and
# looks complete, which is how the two that slgo depends on most went
# missing from the first draft of this file.
#
# A simulator may offer more than this; it will not offer any of them
# unless they are asked for.
#
# verb is the http method, and is marked "?" where I could not establish
# it.  The viewer reaches many of these through helpers that take the
# verb from somewhere else, so guessing from the name would have been
# guessing.  The ones marked are either visible at the call site or have
# been exercised from this tree.
#
# slgo asks for twenty-seven of them at login, in agent.DefaultCaps
# (agent/capsdoc_test.go holds this list to it):
#
#   AvatarPickerSearch  ChatSessionRequest  EventQueueGet
#   FetchInventory2  FetchInventoryDescendents2  GetDisplayNames
#   GetMesh2  GetTexture  InventoryAPIv3  LibraryAPIv3  LSLSyntax
#   ModifyMaterialParams  NewFileAgentInventory  ObjectMedia
#   ParcelPropertiesUpdate  RemoteParcelRequest  RenderMaterials
#   SimulatorFeatures
#   UpdateAgentInformation  UpdateAvatarAppearance
#   UpdateNotecardAgentInventory  UpdateNotecardTaskInventory
#   UpdateScriptAgent  UpdateScriptTask  UserInfo  ViewerAsset
#   ViewerStats
#
# The two-step upload used by everything called Update...Inventory or
# ...UploadFlag is worth knowing once: post an LLSD description of the
# item, get back a one-shot uploader URL, then post the bytes to that.
# The second URL is not a capability and is good once.
